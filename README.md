All context files for Claude sessions live in the app repo at:
https://github.com/charlesheflin-dev/foot-capacity-tracker-app/tree/main/context/

1. `context/claude-instructions.md`
2. `context/system-map.md`
3. `context/lessons-learned.md`
4. `context/active-context.md`
